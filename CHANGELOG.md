# Change Log

All notable changes to the "jupyter-cell-tags" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## 0.7.2

- Feature flags under **Features** so Jumpbacks, Custom Outline, Git Diff, Dependency Chain, Notebook Filter, Durable Kernel, and related tools can be toggled independently.
- Explorer views: All Notebook Tags, Jumpbacks, Custom NB Outline, Executed Cells, Git Modified Cells, Dependency Chain, and Notebook Cell Filter.
- Durable Jupyter server that survives Extension Host restart, with kernel picker integration.
- Tag color, hot-age fade, sort order, rename, and remove-from-all-cells from the All Notebook Tags view.
- Git diff highlights and a Git Modified Cells list vs HEAD or a chosen commit.
- Notebook cell filter/collapse by criteria, jumpbacks for cells and text lines, and dependency-chain highlighting.
- Emoji prefixes on custom views, related settings, and commands.
